# Что сделано и что осталось

## Готово

**Магазин**
- Главная, каталог, категории, коллекции, поиск с подсказками
- Фильтры (размер, цвет, бренд, цена, наличие, скидка) и сортировка — сохраняются в адресе страницы
- Страница товара: галерея, выбор размера и цвета, таблица размеров, отзывы, похожие товары
- Корзина хранится на сервере, цены и остатки проверяются каждый раз
- Оформление заказа в 5 шагов, тестовая оплата
- Избранное (сохраняется в аккаунте после входа)
- Инфо-страницы: о бренде, контакты, доставка, возврат, FAQ, политика, соглашение

**Аккаунт**
- Регистрация, вход, подтверждение email, сброс и смена пароля
- Профиль, адреса, история заказов, повтор заказа

**Админка** (`/admin`)
- Дашборд с графиком выручки
- Товары: создание, редактирование, фото, вариации, остатки, массовые изменения
- Заказы: статусы, отправка, трек-номер, возврат денег, заметки, история
- Покупатели, сотрудники и роли, категории, коллекции, контент, настройки, журнал действий

**Сервер**
- Права проверяются на каждом запросе
- Товар резервируется при заказе — нельзя продать больше, чем есть
- Оплата подтверждается только уведомлением от платёжной системы
- Письма уходят через очередь с повторными попытками

**Тесты**
- 16 unit-тестов (расчёт цены, статусы, роли)
- 32 API-теста (вход, права, корзина, резерв, оплата, webhook)
- E2E-тесты в браузере: покупка от каталога до оплаты и обработка заказа в админке

## Осталось

| Что | Комментарий |
|---|---|
| Промокоды | Расчёт скидки уже есть на сервере, нет API и экранов |
| Реальная оплата | Нужны ключи YooKassa или Stripe — см. [PAYMENTS.md](PAYMENTS.md) |
| Пункты выдачи СДЭК / Boxberry | Сейчас список пунктов задаётся вручную |
| Полный SSR | Сейчас сервер подставляет только SEO-теги (см. [ARCHITECTURE.md](ARCHITECTURE.md)) |
| Юридические тексты | В демо — шаблоны, нужен юрист |
