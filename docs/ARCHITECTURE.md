# Как устроен SILT

## Папки

| Папка | Что внутри |
|---|---|
| `apps/web` | Сайт магазина и админка (React) |
| `apps/api` | Сервер (Express), адрес `/api/v1` |
| `packages/shared` | Общий код: проверка форм, роли, статусы заказов, расчёт цены |
| `prisma` | Схема базы данных и тестовые данные |
| `infra` | Docker и запуск базы данных |
| `e2e` | Автотесты в браузере |

## Главные правила

- **Цены, скидки и остатки считает только сервер.** Браузер лишь показывает результат.
- **Деньги хранятся в копейках** (целые числа), чтобы не было ошибок округления.
- **Пароли** — хеш Argon2id. **Вход** — cookie, которую не может прочитать JavaScript.
- **Админка** проверяет права на сервере при каждом запросе.

## Заказ

1. Покупатель оформляет заказ → сервер пересчитывает сумму и **резервирует товар**.
2. Покупатель уходит на страницу оплаты провайдера.
3. Провайдер присылает серверу уведомление (webhook) → заказ становится «Оплачен».
4. Не оплатил за 30 минут → резерв снимается, заказ отменяется.

Статусы: создан → ожидает оплаты → оплачен → собирается → отправлен → доставлен. Отменить можно до отправки; оплаченный заказ отменяется через возврат денег.

## Оплата

Все провайдеры подключаются через один интерфейс, поэтому их можно менять, не трогая оформление заказа.

- **Mock** — тестовая оплата для разработки. В production выключена.
- **Stripe** и **YooKassa** — готовы к подключению, нужны ключи. Подробнее — [PAYMENTS.md](PAYMENTS.md).

## SEO

Сайт — одностраничное приложение. Чтобы поисковики и соцсети видели заголовки и описания, сервер сам вставляет их в страницу товаров и каталога. Также есть `sitemap.xml` и `robots.txt`.

## Без Docker

Если Docker нет, база запускается командой `npm run db:start`. Redis, хранилище S3 и почтовый сервер необязательны: без них кэш хранится в памяти, фото — в папке `uploads`, письма — в папке `apps/api/.mail`.
