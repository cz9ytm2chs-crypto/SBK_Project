# Оплата

## Как это работает

1. Покупатель нажимает «Оплатить».
2. Сервер сам считает сумму и создаёт платёж у провайдера.
3. Покупатель платит на странице провайдера.
4. Провайдер присылает уведомление (webhook). Сервер проверяет подпись и **сам запрашивает статус у провайдера**.
5. Только после этого заказ становится «Оплачен».

Страница «Спасибо за заказ» ничего не решает — она только показывает статус с сервера.

## Провайдеры

| Провайдер | Для кого | Что нужно |
|---|---|---|
| **Mock** (тестовый) | Разработка | Ничего. В production выключен |
| **YooKassa** | Магазины в России (ИП или ООО) | Договор с ЮKassa, ключи |
| **Stripe** | Магазины за пределами России | Аккаунт Stripe, ключи |

> **Важно:** Stripe не работает с компаниями из России. ЮKassa требует российское юрлицо или ИП. Перед подключением уточните условия у провайдера.

## Подключить YooKassa

1. Получите `shopId` и секретный ключ в личном кабинете ЮKassa.
2. Добавьте в `.env`:
   ```
   YOOKASSA_SHOP_ID=...
   YOOKASSA_SECRET_KEY=...
   ```
3. В кабинете ЮKassa укажите адрес для уведомлений: `https://ваш-сайт/api/v1/webhooks/yookassa`
4. В админке → Настройки → включите YooKassa.

## Подключить Stripe

1. Возьмите секретный ключ в Stripe Dashboard.
2. Создайте webhook на адрес `https://ваш-сайт/api/v1/webhooks/stripe` (события `checkout.session.*`), скопируйте его секрет.
3. Добавьте в `.env`:
   ```
   STRIPE_SECRET_KEY=sk_...
   STRIPE_WEBHOOK_SECRET=whsec_...
   ```
4. В админке → Настройки → включите Stripe.

## Защита

- Данные карт не попадают на наш сервер.
- Сумма всегда берётся из заказа, а не из браузера.
- Повторное уведомление от провайдера не обработается дважды.
- Двойной клик по «Оплатить» не создаёт второй заказ или платёж.
- Если уведомление потерялось, сервер раз в 5 минут сам перепроверяет неоплаченные платежи.
- Не оплатили за 30 минут — заказ отменяется, товар возвращается в продажу.

## Добавить нового провайдера

Создайте файл в `apps/api/src/modules/payments/providers/` по образцу `yookassa.provider.ts` и добавьте его в `providers/index.ts`. Оформление заказа менять не нужно.
